# Projeto Prático — Estrutura de Dados (Tema A: Redes)

FATEC Ribeirão Preto — ADS, 3º semestre
Docente: Prof. Me. Heber Castro

Aplicação de terminal em C que cadastra equipamentos de rede em uma BST
(indexada por ID) e representa as conexões entre eles em um grafo não
direcionado e não ponderado.

## Estrutura

- `include/` — interfaces (.h)
- `src/` — implementações (.c)
- `tests/` — testes reproduzíveis
- `docs/` — relatório técnico (PDF)

## Compilação

```
gcc -Wall -Wextra -std=c99 -Iinclude src/*.c -o bin/sistema
```

(ou `make`, se o make estiver instalado)

## Execução

```
bin/sistema
```
